# Local finite-lens minification candidate

This is a new isolated copy of the accepted two-pass finite-volume profile candidate; it does not modify production or its predecessor. The only rendering change is a bounded source-footprint filter on the optical and same-source environment UV paths.

For each candidate fragment, four evaluations of the same shared `LGButtonOpticsEvaluateWithContact` map at `p ± 0.5` target pixels provide the explicit 2×2 Jacobian in *actual source texels per output pixel*. The exact target-to-source overscan mapper is applied before differencing. The shared scalar helper forms `J Jᵀ`, selects its major singular vector, and leaves `tapCount=1` unless the major singular value exceeds 1.001 (a narrow floating-point deadband around identity). It selects two linear level-zero taps through 2.5 texels and four above that; filter width is capped at 4 source texels. No mip chain, implicit derivative, texture write, extra pass, framebuffer, or readback is involved.

Tap centers are symmetric along the major source-space axis, equally weighted in linear sampled premultiplied RGBA, and individually clamped to physical source half-texel centers. The source-sample budget is at most four taps per path (optical and environment: eight taps total in the dual-path case), plus the original existing fallback reads only when their alpha guard fires. When no minification is detected, the material still takes the prior single linear `src.sample` result with no extra taps. Existing finite profile, `.30R` shoulder, contact/height/normal, C1 displacement cap, background, uniforms/240-byte ABI, 16pt provider domain, lease/freshness policy, and source image are unchanged.

`test_button_minification_macos.sh` is the Mac-only golden entry point: it performs source checks, compiles/runs shared scalar tests, compiles the generated full shader with Apple's Metal compiler, then runs a real offscreen Metal test of no-minification identity, 4-tap checker suppression, opaque black/gray/white energy, premultiplied alpha, and both physical source edges. It is a sampling-kernel test only; the same-input real-material GPU image review and visual acceptance remain NOT_RUN and belong to the parent reviewer.
