# 外域背景积分主线程修正版（组件已实测；整体视觉未放行）

本文件描述原始小锥体候选之后的独立改动，优先于同目录内保留的历史模型说明。正常149项本体、手机build28和系统插件没有替换。

## 为什么修改

原始候选已经过macOS Actions39220742046真实渲染，但未视觉通过。独立坐标诊断发现27,936个积分点全部在按钮内部；自然输入只有51个像素差超过1字节、最大3字节。它主要是主透射附近的轻微平均，不能称为周边色光已经补齐。

## 当前唯一近似及信息来源

只用宿主明确租用、最大每边16pt的二维背景。最近圆角矩形边界由现有SDF的解析梯度得到，积分落在边界外的有限矩形区域：径向[0,L]、切向[-L,L]；L复用既有边带预算`min(bezel,max(1.5pt,0.15*shortest),16pt)`。2×2 Gauss节点等权0.25，真实取4次已捕获像素，不增加外界灯、不用屏幕坐标外的内容，不形成第二份清晰透射像。不是从二维截图逆推出真实反射环境、光线方向或深度。

主透射函数、球冠高度和法线、按压凹陷、原连续AA、主位移上限、纹理契约、240B参数及控件全部保持原finite-cap版本相同；新坐标函数同时由C编译和MSL展开，不能用另一套CPU近似画测试图。

## 连续性和来源安全

- 权重仍是有界Fresnel形状近似乘原有边带，但额外按真实局部厚度平滑归零；避免有限的外域颜色在高度趋零时画出非连续色线。
- 原始取样点必须在实际纹理的半texel物理边界内，也必须在ROI加最多16pt的既有预算内。捕获不足时整项积分失效、直接返回原透射像素，不将不存在的外域夹取成重复边缘像素。
- 无外扩、禁用、零厚度、源外或权重为零时不执行色光采样。对原本零权重的路径增加明确主透射直通，避免隐含混合误差。
- 四点平均线性premultiplied RGBA，alpha仍沿主透射。凸混合只说明颜色不超出参与源的范围，不是严格物理能量守恒或真实reflection证明。
- 有效实时provider目前只接受全不透明的自有子树；透明纹理测试属于shader负控，不能据此宣布provider支持透明捕获或系统屏幕。

## 待实际验收的独立门槛

真实GPU必须通过：只改ROI外颜色而内部逐字节不变，证明新增项影响玻璃内且形状外不变；在父透射对外域无响应的像素上也有变化；同lease强制零权重、实际无padding详细背景、新source仅1ptpadding不足点、全透明/部分透明常量/透明邻居回退；无全片雾化、无固定白圈；同自然背景实际原图有可用改善。

本版本最坏新增4次背景源采样，主连续AA最多4次、主透明回退可能再1次。另有原来的4组完整光学有限差分求值，不能仅用“9次采样”冒充总ALU或手机性能预算。Mac命令计时不等于iPhone或系统帧预算。
