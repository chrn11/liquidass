# 显式设计照明验证（用户已选“验证光照”）

## 这不是实测反射环境

本轮用户在选择卡上允许验证设计照明。由此新增一项**明确标注、默认关闭**的中性柔光环境近似；它不是从二维背景恢复了灯光、深度或Apple的反射环境，也不是固定白圈或复制Apple资源。

候选在原172文件闭合版本上追加`LGDesignedLighting.inc`及生成器接线。原高度、法线、接触凹陷、Snell主透射、外域背景积分、AA、纹理捕获/租约、240B、100ms和UI动作均不改。被拒绝的角权重候选没有合入。

## 具体模型

- 设定一个视图坐标内的中性有限角孔径柔光源：中心方位225°、极角110°，外孔径28°、内孔径14°，smoothstep柔边。它是公开写明的设计参数，不是实测场景信息。
- 同一实际表面法线N、固定视向V产生反射方向R=2(N·V)N−V；仅R落入光孔径才有贡献，不按SDF画周圈描边。
- 系数为介电Fresnel×光孔径coverage×原局部厚度coverage。由现有4个足迹几何求值和中心值构成有限像素平滑，不增加纹理读取或新的光学几何求值。
- 在线性premultiplied通道中作中性单位辐亮度的有界设计混合，输出alpha仍是主透射alpha。这不是完整BRDF/多次反射/能量传输求解。
- 复用局部240B中的`fresnelGlareStrength`作为本次测试显式开关：原builder保持0；Mac试验才设1。运行类的旧shader pin没有更新，产品没有新增设置项或启用路径。不能称作已集成可安装版本。
